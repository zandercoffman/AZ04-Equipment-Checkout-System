# AZ04-Equipment-Checkout-System-2025
The Equipment Checkout System is designed to make it easier to keep track of equipment rentals. The system supports manually entering student and item information as well as importing students from TeacherVUE. Once student and item information is loaded, create rentals by either typing in both the student ID and asset tag number or by using a barcode scanner. Automatically sends email confirmations upon rental creation. See the LICENSE file for licensing information.
